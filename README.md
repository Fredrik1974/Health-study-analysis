# Health-study-analysis
Individuell inlämningsuppgift i Python och statistisk dataanalys.

Python-version: 3.14

Uppgiften innehåller analys av hälsodata med hjälp av Pandas, NumPy, Matplotlib och SciPy.

Del 1: Beskrivande statistik, datavisualisering, simulering, konfidensintervall och hypotesprövning.

Del 2: Vidareutveckling av analysen med återanvändbara funktioner, moduler och klassen HealthAnalyzer. Dessutom genomförs linjär regression med NumPy för att undersöka sambandet mellan ålder och systoliskt blodtryck.

Projektfiler:
- notebooks/health_analysis_del1.ipynb – Analys och resultat från Del 1.
- notebooks/health_analysis_del2.ipynb – Den kompletta analysen med vidareutvecklingen från Del 2.
- src/health_utils.py – Funktioner för statistiska beräkningar.
- src/health_analyzer.py – Klassen HealthAnalyzer för analys av hälsodata.
- data/health_study_dataset.csv – Datasetet som används i analysen.
- requirements.txt – Projektets Python-beroenden.
